# Costs and dependencies

No paid extraction service is required by the initial connectors. Dependencies: public Greenhouse/Lever/Ashby/SmartRecruiters APIs, Personio/Recruitee XML career feeds, and accessible hosted Workday career search/detail responses; Python/PyPI, Node/npm, PostgreSQL and Redis. No API keys are used for these public listing/feed endpoints. SmartRecruiters requires a detail request per listing; Personio may require translated feed requests when default descriptions are empty. Availability and terms can change. No authenticated extraction or anti-bot service is used.

Planning assumptions, not vendor quotes: one small host for API/worker/web plus PostgreSQL/Redis; 20-50 USD/month host budget, 5-15 USD/month backups/storage, domain extra. Validate current vendor prices before purchase. Browser-rendered enterprise connectors could change compute costs substantially and are not included. No production benchmark or measured monthly cost exists yet.

Record requests, bytes, index size, source count, refresh cadence and runtime before selecting infrastructure. At 1,000 sources refreshed every six hours, minimum base enumerations are 4,000/day; pagination/details add requests. Limit per-provider traffic and cache based on permitted semantics. Staff time and access/licensing constraints are the main 78-provider risks.

Workday adds one detail request per job, list-page requests, a robots fetch and boundary/first-page reconfirmation. The current 400-job detail budget and ten-minute run timeout are safeguards, not measured production capacity. Workday is an observed career-site interface without a supported public integration guarantee; XML feed availability and Recruitee’s future authentication policy are external dependencies to monitor.

Private accounts add Argon2 hashing CPU, Redis credential/parser budgets and SQL storage for profiles, sessions and encrypted files/text. One original resume may be up to 5 MiB per account; encryption, extracted text and backups add storage beyond that input size. No external resume/matching model is called and no paid identity/email service is configured yet. Email verification/recovery, upload isolation and production-scale storage require an explicit deployment design and measured costs before public release.
